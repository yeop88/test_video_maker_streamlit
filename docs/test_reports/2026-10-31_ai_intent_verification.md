# 영상 없이 AI로 만든 쇼츠가 프롬프트 의도와 맞는지 + 480×640 출력 (2026-10-31)

환경: Windows 11, RTX 4080 SUPER 16GB, RAM 128GB, Ollama qwen3.5:9b(GPU), 이미지 FLUX.2 [klein] 9B, 동영상 LTX-2.5 (nf4) — 이 컴퓨터 설정(`workdir/device.json`) 그대로.

## 방법 (`tests/test_ai_intent.py`)

주제 4개: 비행기 만드는 과정(사용자가 쓴 주제), 김치볶음밥 만드는 법, 가을 단풍 산속 호수의 아침, 고양이의 하루.

1. AI 대본(`pipeline.plan_ai`, 30초, 정보 전달 말투) → 장면 생성 → 장면 가운데 화면을 비전 LLM(qwen3.5:9b)에 보여 주고 판정
   - **주인공 보임**: 주제의 주인공 피사체(예: 비행기 또는 동체·날개·제트 엔진·객실)가 분명히 보이는가
   - **설명과 맞음**: 그 장면의 한글 장면 설명(`prompt_ko`)의 핵심 내용이 보이는가 (작은 차이는 무시하라고 했지만 꽤 엄격함: 「물결 없음」인데 잔물결이 있으면 X)
2. 고친 뒤에는 480×640으로 쇼츠까지 만들어 크기·소리·길이·잘림 확인
3. 장면 모음 그림을 사람이 직접 봄 (이 폴더의 `2026-10-31_ai_intent/*.jpg`)

고치기 전 측정은 v0.7.0 코드(git worktree)로, 같은 작업 폴더·모델을 써서 했다.

## 사용자가 만든 비행기 쇼츠에서 찾은 문제 (고치기 전, LTX-2.5 동영상)

`airplane_video_existing_before.jpg`

| 장면 설명 | 실제 영상 | 판정 |
|---|---|---|
| 컴퓨터 화면 속 3D 비행기 모델 | 흐릿한 파란 기계 부품 | 주인공 O, 설명 X |
| 로봇 팔이 얇은 금속 판을 접고 조립 | 금속 철골 상자 (비행기 없음) | X / X |
| 좌석·계단·조종실이 채워짐 | 객실 좌석 | O / X |
| 붉은색·흰색 도료를 칠함 | 붉은 동체 (칠하는 모습 없음) | O / X |
| 엔진을 주날개에 고정 | 엔진 덩어리 (자동차 엔진처럼 보임) | O / O |
| 비행기를 바라보는 사람의 눈 | 남자 얼굴만 (비행기 없음) | X / X |

→ 주인공 보임 4/6, 설명과 맞음 **1/6**.

원인: 생성 모델은 장면마다 따로 그려서 쇼츠 주제를 모르는데, 장면 영어 프롬프트에 주인공이 빠지는 일이 있었다 ("robotic arm precisely folding thin metal sheets", "human hand and eye looking at a flying airplane" → 사람 얼굴만). 「engine block」처럼 뜻이 여러 가지인 낱말도 다른 물건이 되었다. 이미지 모델(FLUX.2)은 짧은 프롬프트로도 주제를 잘 지켰지만, 동영상 모델(LTX-2.5)은 프롬프트의 첫 피사체·행동 위주로 그려 이 문제가 크게 드러났다.

## 고친 것

- AI 대본이 주인공 피사체(`subject`, 영어 명사구)를 정하고, 모든 장면 프롬프트에 그 낱말이 있어야 통과 (없으면 장면 번호를 알려 주고 다시 쓰게 함, 그래도 없으면 앞에 붙임). 사람 얼굴·손만, 빈 풍경만 나오는 장면 금지, 모호한 낱말 대신 구체적인 이름.
- 사람이 장면 설명을 고쳐 다시 번역할 때(`english_prompt`)도 주인공을 넣음 (카드에 `subject` 저장, 큐 항목에 전달).
- 이미지 장면 움직임 클립이 그림을 9:16으로 늘려 좌우로 약 18% 눌려 보이던 문제 → 비율을 지켜 채우고 자름.

## 결과

| | 주인공 보임 | 설명과 맞음 |
|---|---|---|
| 비행기, LTX-2.5 동영상 — 고치기 전 (사용자 작업) | 4/6 | 1/6 |
| 비행기, LTX-2.5 동영상 — 고친 뒤 | **6/6** | **5/6** |
| 이미지 3주제(김치볶음밥·호수·고양이) — 고치기 전 | 17/18 | 15/18 |
| 이미지 3주제 — 고친 뒤 | **18/18** | 15/18 |
| (참고) 비행기 이미지 — 고치기 전 | 6/6 | 6/6 |

- 고친 뒤 비행기 동영상: 공장 안 동체, 동체·날개 연결 작업, 객실 좌석, 이륙, 구름 위 비행이 모두 비행기로 나옴. 「제트 엔진을 날개에 장착」 장면만 기수 정면이 나와 설명 X.
- 호수: 고치기 전에는 「호수 위 푸른 하늘과 흰 구름」 장면에 단풍이 없어 주인공 X였는데, 고친 뒤 6장면 모두 단풍 호수.
- 고양이: 6장면 모두 고양이. 설명 X 2개는 세부 차이 — 「눈을 비비며」인데 눈만 감음, 그리고 LLM이 한글 설명은 「공」, 영어 프롬프트는 「toy mouse」로 서로 다르게 써서 생쥐 장난감이 그려진 경우 (생성은 프롬프트대로 됨). 이미지의 「설명과 맞음」은 고치기 전후 같은 수준(실행마다 흔들림).

## 남은 것

- LLM이 한글 장면 설명과 영어 프롬프트를 따로 써서 둘이 어긋나는 경우(공 ↔ 생쥐 장난감)가 있음. 카드에는 한글 설명이 보이므로, 어긋나면 사용자가 보는 설명과 그림이 다름.
- 동영상 모델은 「장착하는 동작」처럼 과정·행동을 그리는 데 여전히 약함 (6장면 중 1개).
- 판정은 비전 LLM이 하므로 엄격함이 들쭉날쭉하다. 장면 모음 그림을 사람이 함께 본다.
