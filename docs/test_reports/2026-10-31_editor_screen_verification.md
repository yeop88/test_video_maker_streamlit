# 편집 화면 (단계 표시줄 · 구간 타임라인 · 카드 세로 미리보기) 검증 (2026-10-31)

환경: Windows 11, RTX 4080 SUPER 16GB, RAM 128GB, Edge (Playwright headless)

## 바뀐 것

- **단계 표시줄**: 작업 화면 위에 ① 분석·구성 → ② 카드 편집 → ③ 쇼츠 만들기 → ④ 결과 받기. 끝난 단계 ✓, 큐에서 도는 단계 ⏳, 지금 할 단계는 강조.
- **구간 타임라인**: 2단계 카드 위에 두 막대.
  - 쇼츠 순서: 카드 차례와 길이 비율 (원본 구간 / AI 장면 색 구분)
  - 원본 위치: 고른 구간(번호), 목소리 구간(VAD), 컷 전환(`pipeline.scene_cuts`), 여러 편이면 이 편의 주제 부분
- **카드 세로 미리보기**: 켜면 원본 구간 카드에 영상 대신 지금 화면·자막 설정으로 그린 1080×1920 장면(시작 장면 + 제목 + 나레이션 첫 두 줄)을 240px로 보여 줌. 큰 배경 프레임 대신 작은 PNG만 캐시.
