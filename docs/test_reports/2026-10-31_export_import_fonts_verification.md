# 작업 내보내기·가져오기 · 자막 글꼴 검증 (2026-10-31)

환경: Windows 11, RTX 4080 SUPER 16GB, RAM 128GB, Ollama qwen3.5:9b, Edge (Playwright headless)

## 1. 작업 내보내기·가져오기 (`project.export_zip` / `import_zip`)

- state.json의 절대 경로를 `@project/<상대 경로>`(작업 폴더 안), `@gen_cache/<파일>`(AI 장면)로 바꿔 담고, 가져올 때 새 위치로 되돌림.
- AI 장면 카드의 미리보기 클립과 원본 그림(img_*.png)을 zip의 `gen_cache/`에 함께 담음. 가져올 때 같은 이름(내용 해시)이 있으면 건너뜀.
- 같은 폴더 이름이 있으면 `_2`, `_3`…을 붙여 새 작업으로.

| 확인 | 결과 |
|---|---|
| 영상 작업 2개 내보내기 → 가져오기 (브라우저 테스트가 남긴 작업) | 14.3MB / 25.0MB, 0.4~0.5초. 분석(영상·오디오·캡처), 결과 영상, AI 장면 미리보기 경로 모두 존재 |
| 결과 영상 빼고 내보내기 | 12.6MB / 17.5MB |
| 빈 workdir(다른 PC 가정)로 가져오기 | AI 장면 2개가 `gen_cache`로 옮겨지고 카드 미리보기 경로가 맞음 |
| `files/../../escape.txt`가 든 zip | 거부, 폴더도 만들지 않음 |
| zip 안에 이 PC의 절대 경로 | 없음 |

## 2. 자막 글꼴 (`shorts_maker/fonts.py`, 설정 `subtitle_font`)

- 이 PC에서 찾은 한글 글꼴: 맑은 고딕, 본고딕(Noto Sans KR), 본명조(Noto Serif KR), 함초롬돋움, 함초롬바탕, 한컴 산뜻돋움, HY헤드라인.
- 한글 확인: '가'의 그림이 빈 상자(.notdef)와 다르면 한글 글꼴. Arial·Times·Consolas·Segoe UI는 거절, 시스템 한글 글꼴은 모두 통과.
- **가변 글꼴 문제 발견**: Noto Sans/Serif KR VF를 그대로 쓰면 libass가 기본 굵기(Thin / ExtraLight)로 그려 자막이 아주 가늘게 나옴 → `fonttools`로 굵기 700 고정 글꼴을 만들어 씀 (처음 한 번 5.7초 / 11.4초, 이후 캐시). 그린 미리보기로 굵어진 것을 확인.
- 글꼴 올리기: 처음에는 「보관함에 넣기」 버튼 + 펼침 영역이었는데, 거절된 파일이 업로드 칸에 남아 다음 파일이 들어가지 않음 → 올리면 바로 넣고, 업로드 칸 키를 바꿔 비우도록 고침.

### verify_pipeline 2차 T3 더킹 실패

T3 더킹 값(나레이션 중 원본 소리 / 나레이션 없을 때)은 1·3·4차 0.211·0.206·0.205, 이전 기록 0.207~0.232인데 2차만 0.368.
2차는 LLM이 구간 2개(12초·9초)에 짧은 나레이션(30자·24자)을 붙여, 나레이션 사이 소리가 바뀌는 경사 구간이 측정에서 차지하는 몫이 커진 경우.
이번 변경(글꼴 파일 고르기)은 소리 섞기를 건드리지 않음. 결과 화면 캡처에서 기본 글꼴(맑은 고딕)로 자막·제목이 그려지는 것도 확인.
