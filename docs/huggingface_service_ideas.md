# Hugging Face 모델 조합 프로젝트 아이디어 10선

> 작성일: 2026-10-29
> [Streamlit으로 배포하기 좋은 Hugging Face 예제 30선](huggingface_streamlit_examples.md)에 나온 모델을 2개 이상 조합해서 만드는 프로젝트입니다.
> 모델 번호(예: `#24`)는 위 문서의 번호입니다.
> **목적**: 비상업적 학습과 포트폴리오. 그래서 비상업 라이선스 모델(EXAONE, FLUX.1-Kontext-dev, MusicGen 등)도 자유롭게 씁니다.

## 한눈에 보기 (난이도 순)

|---|---|---|---|

난이도는 Streamlit MVP를 기준으로 한 주관적인 평가입니다.

**추천 시작점: 3번 AI 회의록 비서.** 1번은 너무 쉬워서 워밍업용으로만 권합니다. 3번은 바로 결과가 보이면서도 긴 입력 처리, 구조화 출력, 캐싱 같은 실제 문제를 다룹니다. 자세한 순서는 맨 아래 [추천 진행 순서](#추천-진행-순서)를 참고하세요.

## 1. 중고거래 판매글 자동 작성 ★★☆☆☆

**한 줄 요약**: 물건 사진을 찍으면 카테고리, 상태 설명, 판매글, 깔끔한 사진까지 만들어 줍니다.

- **조합 모델**
  - `#16` SigLIP2 → 카테고리 제로샷 분류
  - `#12` Florence-2 → 캡션, 제품명·모델명 OCR
  - `#17` BiRefNet → 배경 제거
  - `#5` EXAONE 4.0 → 한국어 판매글 작성
- **Streamlit 화면**: 사진 업로드 → 자동 채워진 입력 폼 확인 → 판매글 미리보기 → 복사 버튼
- **도전 포인트**: 모델 4개를 `@st.cache_resource`로 각각 캐싱하고, `st.session_state`로 단계별 결과를 유지하기
- **난이도 올리기**: 사진 여러 장을 한꺼번에 처리, 판매글 말투 선택(친근함/간결함)

## 2. 반려동물 소리 일지 ★★★☆☆

**한 줄 요약**: 외출 중 녹음한 소리를 분석해 짖음, 울음 같은 이벤트를 기록하고 하루 일지를 써 줍니다.

- **조합 모델**
  - `#29` AST → 소리 분류 (개 짖음, 고양이 울음, 초인종 등)
  - `#24` Whisper → 사람 목소리 구간 받아쓰기
  - `#5` EXAONE 4.0 → "오후 2~3시에 12번 짖었어요" 같은 일지 작성
- **Streamlit 화면**: 녹음 파일 업로드 → 시간대별 이벤트 차트 → 일지 요약 카드
- **도전 포인트**: 몇 시간짜리 오디오를 수 초 단위 창(window)으로 잘라 분류하고, 연속된 이벤트를 하나로 묶기
- **난이도 올리기**: 소리가 거의 없는 구간을 건너뛰어 처리 속도 높이기, 날짜별 비교

## 3. AI 회의록 비서 ★★★☆☆ (추천 시작점)

**한 줄 요약**: 회의나 수업 녹음을 올리면 받아쓰기, 요약, 할 일 목록을 만들어 줍니다.

- **조합 모델**
  - `#24` Whisper large-v3-turbo → 음성을 텍스트로 변환
  - `pyannote/speaker-diarization-3.1` (추가 모델, gated) → 누가 말했는지 구분
  - `#5` EXAONE 4.0 → 요약, 결정 사항, 할 일(담당자·기한) 추출
  - `#9` bge-m3 → 지난 회의록 검색 ("지난주에 정한 발표 순서가 뭐였지?")
- **Streamlit 화면**: 오디오 업로드 또는 `st.audio_input` 녹음 → 진행률 표시 → 탭으로 요약 / 할 일 / 화자별 원문 → Markdown 다운로드
- **도전 포인트**
  - 1시간짜리 오디오를 나눠 처리하고 진행률 보여주기 (`st.progress`)
  - Whisper 결과와 화자 분리 결과를 타임스탬프 기준으로 합치기
  - LLM이 할 일 목록을 항상 정해진 JSON 형식으로 내도록 프롬프트 설계와 검증(`pydantic`)
  - 대화가 길어서 LLM 입력 한도를 넘을 때 나눠서 요약한 뒤 다시 합치기
- **난이도 올리기**: 회의록을 쌓아 두고 bge-m3로 검색하는 기능 추가

## 4. 영수증 가계부 ★★★☆☆

**한 줄 요약**: 영수증 사진을 찍으면 날짜, 가게, 금액, 분류가 가계부에 자동으로 들어갑니다.

- **조합 모델**
  - `#19` DeepSeek-OCR 또는 `#18` Granite-Docling → 글자 인식
  - `#11` Qwen2.5-VL-3B → 날짜, 상호, 품목, 금액을 JSON으로 추출
  - `#5` EXAONE 4.0 → 지출 분류 (식비, 교통, 쇼핑 등)와 월간 소비 코멘트
- **Streamlit 화면**: 사진 업로드 → `st.data_editor`로 추출 결과 확인·수정 → 월별 차트 → CSV 다운로드
- **도전 포인트**: OCR 방식과 VLM 직접 추출 방식의 정확도를 비교하고, 틀리기 쉬운 항목(합계 vs 부가세)을 사람이 고치는 흐름 만들기
- **난이도 올리기**: 직접 만든 영수증 20장으로 정확도 평가표 만들기

## 5. 강의자료 학습 도우미 ★★★★☆

**한 줄 요약**: 수업 PDF와 슬라이드를 올리면 질문에 출처와 함께 답하고, 복습 퀴즈를 만들어 줍니다.

- **조합 모델**
  - `#18` Granite-Docling → PDF를 표·수식까지 Markdown으로 변환
  - `#9` bge-m3 또는 `#8` Qwen3-Embedding → 문서 조각 임베딩
  - `#5` EXAONE 4.0 또는 `#1` Qwen3 → 검색된 내용으로만 답변, 퀴즈 생성
- **Streamlit 화면**: 사이드바에 자료 업로드 → `st.chat_message` 채팅 → 답변 아래에 출처 파일과 페이지 → "퀴즈 모드" 탭
- **도전 포인트**
  - 문서 자르는 방법(chunking)을 바꿔 가며 검색 품질 비교
  - 벡터 DB(FAISS, Chroma 등) 저장과 재사용
  - 자료에 없는 내용은 "모른다"고 답하게 만들기
- **난이도 올리기**: 리랭커(`BAAI/bge-reranker-v2-m3`) 추가, 질문 20개로 답변 품질 평가

## 6. 사진 편집 스튜디오 ★★★★☆

**한 줄 요약**: 사진에서 원하는 부분을 클릭하거나 말로 지정하면, 배경을 바꾸거나 스타일을 바꿔 줍니다.

- **조합 모델**
  - `#14` SAM 2 → 클릭한 물체 영역 분할
  - `#17` BiRefNet → 인물·물체 배경 제거
  - `#21` FLUX.1-Kontext-dev 또는 `#22` Qwen-Image-Edit → "배경을 바닷가로", "수채화 스타일로" 같은 지시 편집
  - `#11` Qwen2.5-VL → 사진을 분석해 편집 아이디어 추천
- **Streamlit 화면**: 사진 업로드 → 클릭으로 영역 선택(`streamlit-image-coordinates` 컴포넌트) → 편집 지시 입력 → 전/후 비교
- **도전 포인트**: 클릭 좌표를 SAM 입력으로 넘기기, 마스크와 원본 합성, 무거운 편집 모델은 Inference API로 분리
- **난이도 올리기**: 편집 히스토리와 되돌리기(undo)

## 7. 우리 아이 맞춤 동화책 ★★★★☆

**한 줄 요약**: 아이 이름, 좋아하는 것, 교훈을 입력하면 삽화, 낭독, 배경 음악이 있는 동화책을 만들어 줍니다.

- **조합 모델**
  - `#5` EXAONE 4.0 → 장면별 동화 작성 (장면마다 그림 프롬프트도 함께 생성)
  - `#20` FLUX.1-schnell → 장면별 삽화
  - `#27` Chatterbox → 부모 목소리로 낭독 (본인이 녹음한 샘플만 사용)
  - `#28` MusicGen → 분위기에 맞는 배경 음악
- **Streamlit 화면**: 입력 폼 → 페이지 넘기기 형식의 그림과 글 → 페이지별 오디오 → PDF 다운로드
- **도전 포인트**
  - 장면이 바뀌어도 주인공 외모와 화풍이 유지되도록 프롬프트 설계
  - 4종류 생성 작업을 순서대로 실행하면서 중간 결과 보여주기
- **난이도 올리기**: FLUX.1-Kontext로 첫 장면 주인공을 참조해서 다음 장면 그리기

## 8. 눈이 되어주는 앱 ★★★★☆

**한 줄 요약**: 카메라로 찍은 장면을 음성으로 설명하고, 음성으로 물은 물건을 찾아 줍니다.

- **조합 모델**
  - `#24` Whisper → 음성 질문 받아쓰기
  - `#10` SmolVLM2 → 장면 설명, 글자 읽기
  - `#15` Grounding DINO → "내 열쇠 어디 있어?" 물건 위치 찾기
  - `#26` Kokoro → 답변 음성 출력
- **Streamlit 화면**: `st.camera_input` 촬영 → `st.audio_input` 음성 질문 → 음성 답변 자동 재생, 찾은 물건에 박스 표시
- **도전 포인트**
  - 질문 의도에 따라 "장면 설명"과 "물건 찾기" 중 어떤 모델을 쓸지 LLM이 고르게 만들기 (간단한 에이전트)
  - 전체 응답 시간을 측정하고 줄이기
- **난이도 올리기**: 큰 버튼, 고대비 화면 등 접근성 설계. Kokoro의 한국어 품질이 부족하면 다른 TTS와 비교

## 9. 영상 자막·번역·더빙 ★★★★★

**한 줄 요약**: 한국어 영상을 올리면 영어 자막과 AI 더빙이 입혀진 영상을 만들어 줍니다.

- **조합 모델**
  - `#24` Whisper → 타임스탬프가 있는 자막(SRT)
  - `#3` Gemma 3 또는 `#5` EXAONE 4.0 → 자막 번역 (앞뒤 문맥 반영)
  - `#26` Kokoro 또는 `#27` Chatterbox → 번역 문장 음성 합성 (Chatterbox는 원래 목소리 유지)
- **Streamlit 화면**: 영상 업로드 → 자막 편집표(`st.data_editor`) → 더빙 생성 → 결과 영상 미리보기(`st.video`)
- **도전 포인트**
  - 번역 문장이 원래 구간보다 길 때 음성 속도 조절 또는 문장 줄이기
  - ffmpeg로 오디오 추출, 합성, 자막 입히기
  - 처리 시간이 길어서 작업 상태 관리 필요
- **난이도 올리기**: 원본 배경음을 분리해서 더빙과 다시 섞기

## 10. 가상 인테리어 ★★★★★

**한 줄 요약**: 방 사진에서 가구를 바꾸거나 벽지와 바닥 스타일을 바꿔 보여줍니다.

- **조합 모델**
  - `#15` Grounding DINO → "소파", "창문" 같은 텍스트로 물체 찾기
  - `#14` SAM 2 → 찾은 물체의 정확한 영역 분할
  - `#13` Depth Anything V2 (Large) → 방의 깊이와 구조 파악
  - `#21` FLUX.1-Kontext-dev → "북유럽 스타일 거실로" 같은 편집
- **Streamlit 화면**: 방 사진 업로드 → 바꿀 대상 입력 → 스타일 선택 → 전/후 비교 슬라이더
- **도전 포인트**
  - Grounding DINO 박스를 SAM 입력으로 넘기는 연결 (Grounded-SAM 방식)
  - 바꾼 부분만 편집되고 나머지는 원본이 유지되는지 확인
  - 비전 모델 4개의 GPU 메모리 관리
- **난이도 올리기**: 깊이 맵으로 가구 크기가 원근에 맞는지 검사

## 추천 진행 순서

| 단계 | 프로젝트 | 익히는 것 |
|---|---|---|
| 0. 워밍업 (선택) | 1번 중고거래 판매글 | 모델 여러 개 캐싱, `session_state` |
| 1. 시작 | 3번 AI 회의록 비서 | 긴 입력 분할, 구조화 출력, 진행률 표시 |
| 2. 심화 | 5번 강의자료 학습 도우미 | RAG, 벡터 DB, 답변 품질 평가 |
| 3. 멀티모달 | 7번 동화책 또는 8번 눈이 되어주는 앱 | 생성 모델 여러 종류, 음성 입출력, 간단한 에이전트 |
| 4. 최종 | 9번 영상 더빙 또는 10번 가상 인테리어 | 비전 모델 연결, 미디어 처리, GPU 메모리 관리 |

## 비상업 프로젝트라도 지킬 것

- **Gated 모델**: pyannote, Gemma, FLUX.1-Kontext-dev 등은 Hub에서 이용 약관에 동의해야 다운로드할 수 있습니다.
- **출처 표시**: 공개 데모나 포트폴리오에 사용한 모델과 라이선스를 README에 적어 두세요.
- **목소리 복제**: 본인 또는 동의를 받은 사람의 목소리만 사용하세요.
- **녹음·사진 데이터**: 다른 사람이 나오는 회의 녹음이나 사진은 동의를 받고, 공개 데모에서는 업로드 파일을 저장하지 않도록 하세요.

## 배포 구조 팁

- 무료 Streamlit Community Cloud에서는 GPU가 필요한 모델(🟡)을 직접 돌릴 수 없습니다. 이런 모델은 HF Inference Providers API로 호출하거나, 로컬·Colab GPU에서 실행해 데모 영상을 남기세요.
- 난이도 ★★★★ 이상 프로젝트는 모델 추론을 별도 함수나 모듈(`models/`)로 나누고, Streamlit 파일(`app.py`)은 화면만 담당하게 만들면 코드 관리가 훨씬 쉽습니다.
